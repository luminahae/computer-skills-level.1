# 컴활1급 필기 특훈

컴퓨터활용능력 1급 필기 대비 모의고사 웹앱 (폰 브라우저에 맞춤)

## 기능
- 문제 581개: 2024 상시 기출 1~5회 + 실전 모의고사 1~5회 (표·그림 포함)
- 60분 타임어택 모의고사 / 한 문제씩 바로 채점 또는 시험처럼 끝나고 채점
- 과목별 성적표 + 합격 판정 (과목당 40점, 평균 60점)
- 실제 시험 점수 기록(날짜별 여러 회) + 합격까지 몇 문제 더 필요한지 분석
- 오답노트 (과목·주제별 정리, 다시 풀기), 핵심요약 (검색, 빈출 필터, 한 장씩 옆으로 넘기기)
- 핵심요약 PDF 저장 버튼 (폰 화면 크기): 빈출 TOP 14쪽 / 전체 요약 119쪽
- 기록은 각자 브라우저(localStorage)에 저장

## 폴더 구조 (파일 10개)
```
index.html          화면 뼈대
css/style.css       디자인 (라이트/다크 모드)
js/app.js           앱 기능 (시험, 채점, 오답노트, 요약, 기록, PDF 저장)
data/questions.js   문제·보기·정답·해설 데이터
data/images.js      문제·해설 그림 93장 (한 파일에 모음)
data/summary.js     핵심요약 데이터
pdf/                핵심요약 PDF (comhwal1-top.pdf 빈출 TOP, comhwal1-summary.pdf 전체)
README.md, 변경사항.txt
```

## 실행
- 내 컴퓨터: `index.html` 더블클릭
- GitHub Pages: 저장소에 이 폴더 내용을 그대로 올리고 Settings → Pages → Branch `main` / `(root)` → Save

## 문제 고치는 법
`data/questions.js`에서 문제 id(예: `"K2-15"` = 2024 상시 2회 15번, `"M3-40"` = 실전 모의 3회 40번)로 검색해서 `q`(문제), `o`(보기), `a`(정답 번호), `e`(해설)를 수정하면 돼요.

※ 문제·해설 출처: 길벗(시나공) 무료 배포 PDF. 개인 학습용.
