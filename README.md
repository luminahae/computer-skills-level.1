# 컴활1급 필기 특훈

컴퓨터활용능력 1급 필기 대비 기출·모의고사 웹앱 (폰 브라우저에 맞춤) · 만든이 HAE

## 기능
- 문제 2,321개: 2024 상시 기출 + 실전 모의고사 + 지난 기출 2010~2020 29회 (전 문항 해설, 틀린 보기 고쳐 쓰기 표시)
- 홈 메뉴: 과목별 풀이 · 랜덤 모의고사 · 맞춤학습 · 오늘의 문제 · 플래시 카드 · 오답노트 · 저장한 문제 · 문제 검색 · 시험 성적 · 학습 분석
- 60분 실전 모의고사: 바로 채점 / 끝나고 채점 / CBT(기출 시험지형 2단 + 답안지), 한 문제씩 또는 스크롤로 쭉
- 진행 중인 회차별 기출 (진행률 %, 연습모드·시험모드)
- 문제 화면: 정답모드, 문제 저장, 문제 정보, 내 풀이 이력
- 학습 결과: 정답 수·점수·소요 시간 + 문항별 걸린 시간·결과
- 학습 분석: 날짜별 정답률·푼 문제 수 그래프, 연속 공부일
- 맞춤학습: 과목별 정답률 레이더 차트 + 약한 주제 학습 로드맵
- 벼락치기: 정답 표시된 채로 훑기, 내가 틀린 문제 추천, 연도·회차·랜덤 시험지 선택
- 핵심요약: 과목 탭·표 정리 카드·차트 종류 그림표·PDF 저장, 플래시 카드
- 시험일 D-day, 실제 시험 점수 분석
- 기록은 각자 브라우저(localStorage)에 저장

## 폴더 구조 (파일 13개)
```
index.html          화면 뼈대
css/style.css       디자인
js/app.js           앱 기능 (패스메이트와 같은 엔진)
js/charts.js        차트 종류 그림
data/exam.js        시험 설정 (과목·시간·회차 묶음)
data/questions.js   문제 데이터
data/images.js      문제 그림
data/summary.js     핵심요약
pdf/                요약·빈출 TOP·벼락치기 정답노트 PDF
```
